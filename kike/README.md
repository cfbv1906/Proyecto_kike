# Proyecto kike

Proyecto final de Realidades Expandidas (Corte 3).

- `/` Página de inicio con dos accesos: realidad aumentada (seguimiento de imagen) y filtro facial.
- `/ar/` Experiencia de realidad aumentada con tarjeta de seguimiento.
- `/filtro/` Filtro facial con seguimiento del rostro.

Publicado con Vercel. El código QR del elemento impreso apunta a la página de inicio.
